The web API added a new part to every workout. Please add it to the app.

WHAT CHANGED

GET /api/plan already returns each movement task like this:

  warmup    -> exercises before the work
  exercises -> the main work
  cooldown  -> stretches after the work

There is now a fourth array, plus one number:

  power         -> bone-loading exercises (hops, drops, marching landings)
  powerSessions -> how many of this week's sessions include it (usually 2)

Example:

  {
    "pillar": "movement",
    "target": 3,
    "warmup":    [ ... ],
    "exercises": [ ... ],
    "power":     [ ... ],
    "powerSessions": 2,
    "cooldown":  [ ... ]
  }

WHAT TO BUILD

1. Run a session in this order:
   warm-up -> work -> power -> cool-down

2. The power items have exactly the same shape as the other three arrays
   (name, props, dose, video). Reuse the same card and the same player.
   No new renderer needed.

3. Show the power block only on the first `powerSessions` sessions of the week.
   Use the `doneThisWeek` counter that is already in the response.

   Example: target 3, powerSessions 2
     session 1 -> warm-up, work, power, cool-down
     session 2 -> warm-up, work, power, cool-down
     session 3 -> warm-up, work, cool-down

   Beginners have target 2 and powerSessions 2, so they always get it.

4. If `power` is missing, draw nothing. Do not invent a default.
   It is missing on purpose for movement snacks, for walk-only sessions,
   and for plans made before 2026-08-29.

5. If `powerSessions` is missing but `power` is there, show it every session.

IMPORTANT RULE

Do NOT add the power exercises into `exercises`.

`exercises` means the main work only. Everything that counts how much she
trained - session length, exercise count, adherence, progress - reads that
array. If a screen needs the whole session, add the arrays up in that screen.

ONE MORE THING

Sessions are longer now, and the length depends on the day:

  beginner   20 min normally, 25 min on a power day
  medium     30 min normally, 40 min on a power day
  advanced   35 min normally, 45 min on a power day
  snacks     5 min, no power block

If the app has session length hardcoded anywhere per fitness level, it is wrong
now. Best fix: add up `dose.estimatedSeconds` from the exercises in the
response instead of using a table.

WHY THIS MATTERS (context, not a task)

Bone density drops in menopause, and impact loading is the one thing exercise
does about it that nothing else does. This block used to be something the AI was
asked to include and often skipped. Now it is a fixed part of the workout. If it
does not show up in the app, the plan loses the thing it is named after.
